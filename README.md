# OceanScope · Interactive Demo

Static release of OceanScope for browser-based research inspection. Open the GitHub Pages link in this repository.

Start with frame1049 in 3D. The top tabs open Height & ROI, Field slices, Time analysis, and Reports & restore while retaining the current view.All96 frames have native-SDF3D surfaces and height/sequence results. Full volume and velocity slices cover1001,1049,1096. New surface frames load about1 MB at Balanced or3 MB at Fine, on demand; playback waits for each verified frame. No temporal interpolation is used. Download PNG for presentations, CSV for values and JSON to resume.

JSON reports use this public release’s source-summary identity. Local-edition reports with a different identity are intentionally rejected. This is an interactive inspection tool, not a training service or model-ranking claim.

The public source summary distinguishes provided claims from verified data hashes. See release-manifest.json for file integrity and source revision. Frontend third-party notices are included. No license for upstream research data is inferred.
